# Макеты

Четыре макета портфолио Елены Белоусовой и четыре макета Pro Concept.

Главная страница: `index.html`. Фотографии загружаются с Wix CDN, шрифты — с Google Fonts. Для просмотра нужен интернет.

Статические HTML-страницы, сборка не требуется. Публикация через GitHub Pages из корня ветки `main`.
